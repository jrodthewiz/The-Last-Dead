The user rejected the arm appearance in `output/fps-animation-approval`. Earlier rig and capture passes established mechanics, but the sleeve had a long uniform upper volume, a swollen/pinched elbow and an abrupt glove transition. Artistic acceptance is reopened. The earlier phrase “animation readiness is verified” must not be read as approval of these forms.

The active `craft_authorship_skeptic` role read the project review contract and inspected the actual native images. It rejected the original and the first replacement. The first replacement removed the inherited elbow sphere but introduced a visible circumferential pinch in both neutral support-arm and recoil views. The judge explicitly withheld material approval when that draft also exported white because a Blender 2.93 CustomData layer reference was invalidated by UV creation. Reacquiring the color layer fixes the source; a color-only draft transfer checked position identity and every non-color byte.

The repair is authored in `scripts/author-fps-sleeves-v4.py` from the preserved `Before_Tailored_Sleeves_v4.blend`. It replaces the inherited sphere/remesh garment with a sleeve loft, intentional upper/forearm taper, narrow wrist facing and longitudinal seam. The second experiment adds an elbow cloth pivot and blends bend rotations in `fps-arms.js` to retain the ring volume. Folds are shallow and aligned to the elbow turn, rather than hand-local X. Existing fitted glove geometry/weights, original bind bones and Actions remain invariant; the cloth pivot is an intentional new deform bone.

Acceptance requires the representative Breach pair at ordinary gameplay scale and neutral diffuse in the same camera at idle, recoil and recovery. No swollen elbow, circumferential pinch, cuff void/intersection or exposed garment end may remain. Review visible upper-arm dominance separately; shortening concealed cloth alone can change the runtime shoulder constraint and is not a proven repair. Other weapon sleeves remain unchanged until the representative clears these confirmed blockers. The user retains final visual approval.
